'matches' means the wiring tables' label for the pin uses the pinout's word for it (Coil, Injector, MAP...); 'matches tune name' means it uses the
tune's name for that output; 'nothing to compare' means the tables give no label to compare.
Confirm in PE3Monitor before first power-up
Which function an output switches is not readable from the tune, so check these by eye. A relay wired to an output nobody assigned is caught
here.
[  ] PE3Monitor > Tuning > Digital Outputs: DO2 on MAIN-2 is set to switch what the wiring tables put on it:
W7 | ECU_COMM.16 | ECU_MAIN.2 | DO3 jumper
[  ] PE3Monitor > Tuning > Digital Outputs: DO10 (named 'Fuel Pum' in the tune) on MAIN-6 is set to
switch what the wiring tables put on it: Fuel Pump Relay Control / K4 - Fuel Pump
[  ] PE3Monitor > Tuning > Digital Outputs: DO1 (named 'Fan' in the tune) on MAIN-11 is set to switch what
the wiring tables put on it: Fan Relay Control / K5 - Fan
[  ] Then, per Performance Electronics: name every digital output under Engine > Setup Digital Names
(that is what this check reads from the tune), and switch each one from the Output Diagnostics window to
confirm the relay wired to it actually clicks. A name in the tune does not prove the physical wiring;
switching the output does.
Only the channel names in the tune were read, not the settings behind them (thresholds, priming, input
modes). A match means the names and the wiring agree, not that the outputs behave correctly.
Pinout: Performance Electronics, PE3-84XX Pin Out.
